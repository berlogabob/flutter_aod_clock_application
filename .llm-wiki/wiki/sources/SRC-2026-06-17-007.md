# AOD (Always-on Display).md

## Summary

Always-on Display (AOD) is a mobile device feature that allows specific information, such as the current time or incoming notifications, to be visible on the screen even when the device is locked.\n\nThe display typically appears in a dimmed state to conserve power while remaining accessible without requiring the user to interact with the hardware.

## Key Takeaways

- Displays time or notifications on a dimmed screen when the device is in its "locked" state.
- Commonly used feature on many mobile devices.
