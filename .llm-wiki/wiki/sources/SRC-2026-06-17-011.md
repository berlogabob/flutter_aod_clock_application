# Jitter.md

## Summary

Jitter is a technique used in display technology to mitigate the risk of "burn-in," which occurs when stationary pixels remain in the same position for long durations. By intentionally introducing slight movements into these static elements (such as the position of a clock), the system ensures that no single set of pixels remains constant.

The movement typically happens on a periodic basis, such as every few minutes, to shift pixels slightly across the screen. This prevents the permanent marking or "ghosting" associated with fixed UI components on various types of display panels.

## Key Takeaways

- Jitter is used to prevent burn-in on displays by moving static elements.
- Static elements like clock positions are shifted slightly every few minutes.
