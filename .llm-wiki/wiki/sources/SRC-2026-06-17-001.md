# Architecture.md

## Summary

The source describes the technical architecture of a Flutter-based application designed for displaying time (likely an Always On Display/Clock app). The architecture is modularized into configuration, assets, native platform wraps (covering six major platforms), and core application logic. Specifically, it utilizes a `NightstandAODApp` root which hosts a `ClockScreen` to manage complex time-related states and visual offsets.

The data flow follows a reactive update pattern where the system clock triggers periodic updates within the app's state. While high-frequency timers handle standard string representation of time, minute-level ticks trigger "Burn-in Prevention" logic. This logic recalculates dynamic translation offsets (jitter) every 5 ticks to prevent visual artifacts on display hardware while updating the UI via `setState`.

## Key Takeaways

- The app follows a standard Flutter widget architecture with main.dart as the configuration entry point.
- It features comprehensive cross-platform support (Android, iOS, Linux, MacOS, Web, Windows) via platform-specific native wraps.
- The system uses a reactive update pattern where periodic timer triggers from the OS drive state changes.
- Burn-in prevention is achieved by calculating position jitter every 5 ticks during minute updates.
