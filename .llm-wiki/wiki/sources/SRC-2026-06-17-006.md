## Summary

The nightstand_aod_clock is a minimal, accessibility-focused "Always-On Display" (AOD) clock application built with Flutter. It is specifically optimized for mobile devices with AMOLED screens, utilizing true black backgrounds to preserve battery life and minimize ghosting. The project incorporates unique features such as dyslexia-friendly fonts and an automated positional jitter system that shifts the clock's location every five minutes to prevent screen burn-in.\n\nThe application follows a modular architecture where core logic is handled by Dart code within the lib folder, while native platform wrappers provide support for Android (Kotlin), iOS/macOS (Swift), Linux/Windows (C++), and Web. Key UI behaviors include sticky immersive mode to hide system bars and wakelock integration to ensure the display remains active on supported mobile devices.

## Key Takeaways

- Designed specifically for AMOLED devices with true black backgrounds to save power.
- Includes automatic position jittering every 5 minutes to prevent screen burn-in.
- Supports multi-platform deployment including Android, iOS, Linux, macOS, Windows, and Web.
- Features accessibility support through the use of OpenDyslexic fonts.
