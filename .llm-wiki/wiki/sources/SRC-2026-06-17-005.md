# README.md

## Summary

The nightstand_aod_clock is an accessibility-focused Always-on Display (AOD) application designed to provide a large, high-contrast clock for Android and other platforms. It specifically addresses readability issues for users with dyslexia by implementing the OpenDyslexic font while maintaining a minimalist design.

Technically, the project is built using the Flutter framework and Dart language, utilizing Skia/CanvasKit for its graphics rendering. The application is engineered for power efficiency—employing black backgrounds to benefit AMOLED displays—and includes specific mechanisms to prevent screen burn-in during static display usage.

## Key Takeaways

- Designed specifically for high readability with OpenDyslexic font support for users with dyslexia.
- Optimized for power efficiency on AMOLED screens by using a black background.
- Includes hardware-specific mitigations such as burn-in prevention for static displays.
- Developed using the Flutter framework and Dart programming language.
