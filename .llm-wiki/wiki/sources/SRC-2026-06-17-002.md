## Summary

This document outlines the development and design decisions for the application, highlighting a philosophy that favors "Minimum Viable Aesthetic." This approach prioritizes functionality and power efficiency over decorative UI elements. Key technical choices include specific jitter calculations intended to prevent screen burn-in through geometric offsets and the adoption of OpenDyslexic font to enhance accessibility.\\n\\nThe source also details UI implementations, such as the use of 'immersiveSticky' mode for system bars, and provides standard build commands for Android, iOS, and desktop platforms using the Flutter framework.

## Key Takeaways

- The app follows a 'Minimum Viable Aesthetic' approach to balance performance and design.
- Jitter logic uses specific pseudo-random constants to prevent screen burn-in without distracting the user.
- Immersive mode is enabled on startup to provide a seamless UI experience by managing system bars.\\n
- OpenDyslexic font is utilized as the primary typeface to meet accessibility standards for users with reading difficulties.
