# Glossary.md

## Summary

This glossary defines technical terms related to mobile device display technologies, software mechanics, and UI design components. It covers hardware-specific issues such as screen burn-in on OLED panels and the corresponding "Jitter" technique used to mitigate it. It also details power management features like Wakelocks and display states like Immersive Mode.\n\nThe source further explores graphics rendering tools used by frameworks like Flutter and accessibility considerations, specifically the design principles behind Dyslexic Fonts. The documentation serves as a reference for developers and designers working on mobile environments where screen health and user experience are prioritized.

## Key Takeaways

- AOD provides information on locked screens without full activation.
- Burn-in is a hardware risk for OLED/AMOLED displays from static images.
- Wakelocks are used by apps to prevent device sleep during specific tasks.
- Immersive Mode maximizes screen real estate by hiding system navigation elements.
- Jittering pixels is a technique to preserve display longevity.
- Flutter relies on Skia and CanvasKit for its rendering pipeline.
- Dyslexic fonts are accessibility tools that modify character shapes for easier reading.
