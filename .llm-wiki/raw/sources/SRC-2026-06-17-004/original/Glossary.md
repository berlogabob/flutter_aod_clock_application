# Glossary of Terms

| Term | Description |
| :--- | :--- |
| [[AOD (Always-on Display)]] | A feature on many mobile devices that displays information (like time or notifications) on a dimmed screen while the device is in a "locked" state. |
| [[Burn-in]] | Permanent discoloration or ghosting caused by static images being displayed for long periods on AMOLED and OLED screens. |
| [[Wakelock]] | A mechanism in Android that allows an application to keep the device's CPU awake even when the screen is off or the user is not interacting with it. |
| [[Immersive Mode]] | A display state where system UI elements like status bars, navigation bars, and buttons are hidden to maximize the viewable area. |
| [[Jitter]] | The intentional slight movement of a static element (like the clock position) used here to prevent burn-in by shifting pixels slightly every few minutes. |
| [[Skia and CanvasKit]] | Graphics engines used by Flutter to render high-performance 2D and 3D graphics on multiple platforms. |
| [[Dyslexic Font]] | Fonts designed specifically to improve readability for people with dyslexia, often featuring distinct character shapes and weights (e.g., OpenDyslexic). |
